# ファンド別オフィス設計

更新日: 2026-08-24

## 目的

3つの架空ファンドが応援する会社の分野を、別々の仕事場として見せる。子どもが商品名だけでなく「どのような会社が集まるチームか」を、部屋の雰囲気から想像できるようにする。

## 部屋の構成

| 商品               | 部屋             | 色と家具の方向性                                                         |
| ------------------ | ---------------- | ------------------------------------------------------------------------ |
| せかい成長ファンド | 世界コラボルーム | 青を基調に、本棚、地図を想起させる絵、ホワイトボード、交流用ソファを置く |
| くらし安心ファンド | くらしラウンジ   | 緑と木の色を基調に、植物、本棚、時計、休憩用ソファとコーヒーを置く       |
| みらい技術ファンド | 未来テックラボ   | 紫と青を基調に、複数のPC、ホワイトボード、実験スペースを置く             |

MVPではPixel Agentsに同梱された既存家具を組み合わせる。新しい画像素材は追加せず、公開前の素材ライセンス確認という既存方針を維持する。

## 閲覧ルール

- 子ども画面の上部に3つの部屋タブを常時表示する。
- 未購入の商品も部屋を「見学」できる。購入を急がせるために部屋をロックしない。
- 購入済みの商品はタブへ「活動中」、未購入の商品は「見学」と表示する。
- 各部屋には、その商品に対応するキャラクターだけを表示する。
- 未購入商品の部屋は無人の状態で表示する。
- 部屋の切り替えは閲覧だけであり、買付、価格、口座状態を変更しない。
- 仕事イベントの音符・汗と学びのメモは、現在見ている部屋の商品についてだけ表示する。

## 実装上の境界

- 3部屋は同じ行数・列数とし、切り替え時のカメラ位置と入口位置を共通にする。
- 商品とキャラクターの対応は商品カタログを正本とする。
- 保有商品全体は口座APIから読み取り、選択中の部屋に対応する1人だけを描画対象にする。
- 部屋を切り替えてもキャラクターの幸福度や成績を評価しない。
