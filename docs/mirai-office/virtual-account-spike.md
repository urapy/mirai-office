# 仮想口座・画面接続スパイク

更新日: 2026-08-23

## 目的

保護者が仮想の積み立てを行い、固定価格シナリオの日付を進め、その結果を子ども画面の金額と会社・社会の架空ニュースへ反映する最初の縦切りを確認する。

実在する証券会社、証券API、実口座、個人情報は一切使用しない。状態はメモリ上だけに置き、ページを再読み込みすると初期化される。

## 実装した流れ

1. 初期状態は元本・評価額とも0円。
2. 保護者画面で10,000円を積み立てる。
3. 3つの架空商品から1つを選び、当日の価格で自動購入する。
4. 「1日進める」で固定JSONの次の価格へ進む。
5. 元本、評価額、損益、保有数量を再計算する。
6. 子ども画面にも元本、評価額、損益を表示する。
7. 固定ニュースまたは中立的な値動き説明を表示する。
8. 初めて購入した商品に対応するオフィスの仲間を1人表示し、最大3人のチームにする。

子ども画面と保護者画面は明示的なボタンで切り替える。MVP方針どおりPINはまだ実装しない。

## 状態とイベント

`webview-ui/src/miraiOffice/virtualAccount.ts`に表示から独立した状態遷移を置く。

主な状態:

- 選択中のシナリオID
- 現在の日（1〜30日）
- 現金
- 元本
- 保有数量
- 商品ごとの保有数量
- 投資イベント履歴

現在のイベント:

- `deposit`: 仮想入金
- `purchase`: 架空商品の自動購入
- `priceUpdated`: 固定シナリオの日次価格更新

評価額は`現金 + 保有数量 × 現在価格`を円単位へ丸める。損益は`評価額 - 元本`とする。数量は計算時に丸めず、画面だけ小数第4位まで表示する。

## 画面

`VirtualAccountPanel.tsx`をブラウザ実行時に表示する。

### 子ども画面

- 積み立てている商品名と説明
- 30日中の現在日
- 元本、評価額、損益
- 会社・社会の架空ニュースまたは中立的な値動き説明
- 現在のチーム人数（0〜3人）
- 保護者画面への切替

### 保護者画面

- 3つの架空商品から積立先を選択
- 1,000円、5,000円、10,000円から積立額を選択
- 商品選択とは別の3価格シナリオ設定
- 現在価格、元本、評価額、損益、保有数量
- 10,000円の積立
- 1日進める
- 初期化
- 学習用の完全な仮想口座である旨の表示
- 現在のチーム人数（0〜3人）

## チーム成長

商品ごとの保有数量から、表示するキャラクターを決める。

| 初めて購入した商品 | オフィスに参加する表示名 |
| ------------------ | ------------------------ |
| せかい成長ファンド | せかい成長ファンド       |
| くらし安心ファンド | くらし安心ファンド       |
| みらい技術ファンド | みらい技術ファンド       |

同じ商品への追加積立、価格の上昇・下落、損益では人数を変えない。キャラクターが値下がりの責任を負う印象を避け、保護者が初めて商品を購入したことだけを参加のきっかけにする。リセットまたはシナリオ変更では0人へ戻す。

## テスト結果

- 初期口座が元本・評価額・損益0円になる。
- 10,000円の入金と購入で1口保有する。
- 日付を進めても数量は変わらず、固定価格から損益を計算する。
- 追加積立は当日の価格で数量を追加する。
- 30日目より先へ進めない。

Webviewは15ファイル、103テストが成功した。リポジトリ全体のビルドも成功した。
