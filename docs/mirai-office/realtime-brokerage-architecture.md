# 仮想証券口座・リアルタイム市場アーキテクチャ

更新日: 2026-08-23

## 目的

3つの架空商品について、サーバーが生成する再現可能なリアルタイム価格を、仮想証券口座とみらいオフィスの両方へ配信する。実在市場、証券会社、実口座、個人情報には接続しない。

## 構成

| コンポーネント      | ローカルURL             | 責務                                                 |
| ------------------- | ----------------------- | ---------------------------------------------------- |
| `simulation-server` | `http://127.0.0.1:4310` | 価格生成、仮想口座、積立、履歴、SSE配信              |
| `brokerage-ui`      | `http://127.0.0.1:5174` | 保護者向けの証券口座風ダッシュボード、チャート、積立 |
| `webview-ui`        | `http://127.0.0.1:5173` | 子ども向けのオフィス体験と口座サマリー               |

価格と口座残高の正本は`simulation-server`だけに置く。2つのUIはRESTで初期状態を取得し、価格更新をSSEで受け取る。

## API

- `GET /api/health`: 稼働状態
- `GET /api/products`: 架空商品一覧
- `GET /api/quotes`: 現在価格
- `GET /api/accounts/demo`: 仮想口座スナップショット
- `GET /api/accounts/demo/history`: 入金・買付履歴
- `POST /api/accounts/demo/contributions`: 選択商品への積立と即時買付
- `POST /api/accounts/demo/reset`: 仮想口座の初期化
- `GET /api/stream/quotes`: SSEによる価格・口座・履歴の配信

積立APIは正の整数円と既知の商品IDだけを受け付ける。MVPでは売却、出金、信用取引、注文板を実装しない。

## 価格生成

- 初期価格は3商品とも10,000円。
- 1秒を1ティックとし、商品ごとの傾向、周期、シード付き疑似乱数を合成する。
- 同じシードとティック列から同じ変化を再現できる。
- 価格は1円単位の正の整数とし、短期間でゼロ以下にならない下限を持つ。
- UIの再描画や接続数は価格生成へ影響しない。

これは教育用の架空値であり、将来予測や投資助言ではない。

## 画面方針

仮想証券口座は、資産サマリー、商品カード、価格チャート、保有一覧、履歴を持つ独自のモダンUIとする。特定証券会社の配色、文言、画面構成、ロゴ、アイコンを複製しない。

みらいオフィスではリアルタイム金額を表示するが、キャラクターをティックごとの値上がり・値下がりへ反応させない。音符と汗は引き続き架空ニュースの内容だけに連動させる。

## 障害時

- API停止中は画面に接続停止を明示し、最後に受信した価格を「更新停止」として表示する。
- APIへ接続できない状態で積立を成功扱いにしない。
- SSEはブラウザ標準の自動再接続を利用し、再接続後にRESTスナップショットで補正する。
- 状態は当初メモリのみとし、ページ再読み込みでは維持、API再起動では初期化する。永続化は状態遷移の検証後に追加する。

## セキュリティ境界

- 全サービスを`127.0.0.1`だけへバインドする。
- CORSはローカルの2画面だけを許可する。
- 実名、認証情報、実口座番号を扱わない。
- 秘密情報、口座状態を`localStorage`へ保存しない。
