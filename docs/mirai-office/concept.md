# サービスコンセプト

## 仮称

みらいオフィス

## 問題認識

子ども名義の資産形成制度であっても、商品選択、入金、管理は保護者が担う可能性が高い。そのままでは、子どもにとって「知らないところで数字だけが増減する口座」になり、投資と企業・社会・時間のつながりを学ぶ機会になりにくい。

## 提供価値

証券口座に相当する情報を、子どもが理解できる「働く人たちのオフィス」に翻訳する。子どもは、投資を値当てゲームとしてではなく、自分のお金が会社や社会の活動に参加し、長い時間をかけて働く体験として理解する。

子ども向けの基本表現は次とする。

> 会社や社会の活動に、自分のお金にも参加してもらう。活動が成長すると、その成果の一部を受け取れることがある。

「必ず増える」「企業へ直接お金を渡す」とは説明しない。

## 体験の比喩

| 投資上の出来事   | みらいオフィスでの表現                               |
| ---------------- | ---------------------------------------------------- |
| 積立・買付       | 新しい仲間が入社する                                 |
| 投資信託         | 複数の会社・地域で構成されたチーム                   |
| 分配金・配当     | チームが成果を持ち帰る                               |
| 日々の値動き     | 元本・評価額・損益と、会社や社会の短い架空ニュース   |
| 長期の積み上がり | 投資額と評価額の推移。成長の比喩は必要性を再検討する |
| 将来目標         | 大学、旅行などの目標施設を育てる                     |

値上がりを笑顔、値下がりを悲しみとして表現しない。値下がりを特定のキャラクターや一つのプロジェクトの失敗と断定せず、景気、売れ行き、費用、将来への期待など複数の要因があると伝える。値動きがあってもキャラクターは仕事を続ける。

## 主な利用者

- 子ども: 状況を直感的に眺め、企業・世界・長期投資に興味を持つ。
- 保護者: 仮想口座を設定し、正確な金額・履歴・進捗を管理する。

## 成功の初期仮説

最初に検証するのは金融APIの技術ではなく、子どもが画面を見て「この人たちは何をしているの？」と自然に質問し、親子の対話が生まれるかどうかである。

## 開発段階

1. 完全な仮想口座: ローカルWebアプリで積立、値動き、評価額、損益、成果を再現する。
2. 市場価格のみ連携: 保有数量は仮想のまま、公開市場データに連動する。
3. 実口座の読み取り専用連携: 正式なAPIから残高・保有商品だけを取得する。売買・出金は行わない。
